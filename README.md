# IRON4FUN - Open Water Swim Training Camp

This repository contains the landing page for **IRON4FUN edition Cascais**, an open water swim training camp organized by **Swim4Fun**. The page is designed for triathletes who want to familiarize themselves with the swim course before competing in **IRONMAN Portugal-Cascais** and **IRONMAN 70.3 Portugal-Cascais**.

## About the project

The Atlantic Ocean in Cascais can be unpredictable. **IRON4FUN** provides guided open water reconnaissance sessions led by local coaches. The landing page serves as an overview of the camp, scheduling, pricing, and allows athletes to pre-register for upcoming sessions.
